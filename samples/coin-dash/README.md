# Coin Dash (v0.2 sample game)

Player lari/lompat, 3 koin, 1 musuh patroli, skor + nyawa, SFX + musik loop,
animasi jalan, kamera mengikuti player, kondisi menang.

Kontrol: `Kanan/Kiri` gerak, `Spasi` lompat.

Catatan: sprite dan SFX adalah placeholder yang digenerate
(`walk0`/`walk1` beda posisi kaki; koin dan musuh 8x8 piksel).
